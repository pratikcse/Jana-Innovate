JANA INNOVATE React Prototype

Requirements:
- Node.js 18+ (Node 20/22 recommended)
- VS Code

Run:
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: npm install
4. Run: npm run dev
5. Open the Local URL Vite shows, normally http://localhost:5173

Build:
npm run build

This is a front-end prototype. AI analysis and data are simulated for the SIH demonstration.
